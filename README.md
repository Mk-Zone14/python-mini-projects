# 🐍 Python Mini Projects

A collection of small Python projects exploring **Python, mathematics, animation, creative coding, and visual programming**.

Each project is built as a hands-on experiment to learn new programming concepts while creating something visually interesting. This repository will continue to grow as I explore more mathematical patterns, animations, and simulations.

## 🚀 Running the Projects

Clone the repository:

```bash
git clone https://github.com/Mk-Zone14/python-mini-projects.git
```

Navigate into the project:

```bash
cd python-mini-projects
```

Run any project:

```bash
python heart_pattern.py
```

Replace `heart_pattern.py` with the name of the project you want to run.
