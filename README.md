## 🚀 Running the Projects

Clone the repository:

```bash
git clone https://github.com/Mk-Zone14/python-mini-projects.git
```

Navigate into the project folder:

```bash
cd python-mini-projects
```

Run any project:

```bash
python heart_pattern.py
```

Replace `heart_pattern.py` with the name of any project you want to run.
